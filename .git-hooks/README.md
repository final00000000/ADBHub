# Git Hooks 安装指南 - 禁止 AI 署名

## 自动安装（推荐）

### Windows (PowerShell)

```powershell
# 初始化 Git 仓库（如果还没有）
git init

# 创建 hooks 目录
New-Item -ItemType Directory -Force -Path ".git\hooks"

# 复制 PowerShell hook
Copy-Item ".git-hooks\commit-msg.ps1" ".git\hooks\commit-msg.ps1"

# 创建 bash wrapper（Git 会调用这个）
@"
#!/bin/sh
powershell.exe -ExecutionPolicy Bypass -File "`$(dirname `$0)/commit-msg.ps1" "`$1"
"@ | Out-File -FilePath ".git\hooks\commit-msg" -Encoding ASCII

# 设置执行权限（Git Bash）
git update-index --chmod=+x .git/hooks/commit-msg
```

### Linux/macOS (Bash)

```bash
# 初始化 Git 仓库（如果还没有）
git init

# 复制 hook
cp .git-hooks/commit-msg .git/hooks/commit-msg

# 设置执行权限
chmod +x .git/hooks/commit-msg
```

## 手动安装

1. 确保已初始化 Git: `git init`
2. 进入 `.git/hooks/` 目录
3. 创建 `commit-msg` 文件
4. 复制对应平台的 hook 脚本内容
5. 设置执行权限

## 测试 Hook

```bash
# 测试包含 AI 署名的提交（应该被拒绝）
git commit -m "feat: add feature

Co-authored-by: Claude <claude@anthropic.com>"

# 正常提交（应该成功）
git commit -m "feat: add feature"
```

## 全局配置（可选）

如果想在所有项目中启用此 hook：

```bash
# 设置全局 hooks 目录
git config --global core.hooksPath ~/.git-hooks

# 创建目录并复制 hook
mkdir -p ~/.git-hooks
cp .git-hooks/commit-msg ~/.git-hooks/commit-msg
chmod +x ~/.git-hooks/commit-msg
```

## 临时禁用 Hook

如果某次提交需要跳过检查：

```bash
git commit --no-verify -m "your message"
```

- `Co-authored-by: Claude`
- `Co-authored-by: ChatGPT`
- `Co-authored-by: Copilot`
- `Generated by AI`
- `AI-assisted`
- `With assistance from Claude`
- `Pair programmed with AI`

## 卸载

```bash
rm .git/hooks/commit-msg
rm .git/hooks/commit-msg.ps1
```

## 故障排除

### Hook 未执行

```bash
# 检查文件是否存在
ls -la .git/hooks/commit-msg

# 检查权限（Linux/macOS）
chmod +x .git/hooks/commit-msg

# 检查 Git hooks 是否被禁用
git config core.hooksPath
```

### PowerShell 执行策略错误

```powershell
# 临时允许脚本执行
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## 自动化安装脚本

### setup-hooks.ps1 (Windows)

```powershell
#!/usr/bin/env pwsh

Write-Host "正在安装 Git hooks..." -ForegroundColor Cyan

# 检查是否是 Git 仓库
if (-not (Test-Path ".git")) {
    Write-Host "初始化 Git 仓库..." -ForegroundColor Yellow
    git init
}

# 创建 hooks 目录
$hooksDir = ".git\hooks"
if (-not (Test-Path $hooksDir)) {
    New-Item -ItemType Directory -Force -Path $hooksDir | Out-Null
}

# 复制 PowerShell hook
Copy-Item ".git-hooks\commit-msg.ps1" "$hooksDir\commit-msg.ps1" -Force

# 创建 wrapper
$wrapper = @"
#!/bin/sh
powershell.exe -ExecutionPolicy Bypass -File "`$(dirname `$0)/commit-msg.ps1" "`$1"
"@

$wrapper | Out-File -FilePath "$hooksDir\commit-msg" -Encoding ASCII -Force

Write-Host "✓ Git hooks 安装成功！" -ForegroundColor Green
Write-Host ""
Write-Host "Hook 功能: 自动检测并阻止包含 AI 署名的提交" -ForegroundColor Cyan
Write-Host "测试命令: git commit -m 'test: AI署名检测' --allow-empty" -ForegroundColor Gray
```

### setup-hooks.sh (Linux/macOS)

```bash
#!/usr/bin/env bash

echo "正在安装 Git hooks..."

# 检查是否是 Git 仓库
if [ ! -d ".git" ]; then
    echo "初始化 Git 仓库..."
    git init
fi

# 创建 hooks 目录
mkdir -p .git/hooks

# 复制 hook
cp .git-hooks/commit-msg .git/hooks/commit-msg

# 设置执行权限
chmod +x .git/hooks/commit-msg

echo "✓ Git hooks 安装成功！"
echo ""
echo "Hook 功能: 自动检测并阻止包含 AI 署名的提交"
echo "测试命令: git commit -m 'test: AI署名检测' --allow-empty"
```

使用:
```bash
# Windows
powershell -ExecutionPolicy Bypass .\setup-hooks.ps1

# Linux/macOS
chmod +x setup-hooks.sh
./setup-hooks.sh
```
